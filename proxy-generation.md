# Proxy Generation

{% hint style="info" %}
In this segment, you'll receive direction on the choices and capabilities accessible during proxy generation.&#x20;

Our dashboard provides customers with a range of options for generating different formats, which is great for flexibility. Additionally, the ability to target proxies by country, state, and city allows customers to optimize proxy usage for specific geographic locations. This can be particularly useful for businesses that have a strong local presence and need to gather data from specific regions. Overall, these features provide customers with greater control and customization options, which can ultimately lead to more efficient and effective use of proxies.
{% endhint %}

1. Navigate through the **My Products -> Residential Proxies -> Generation.**

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 2 .30.17.jpg" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
The proxies cannot be generated unless a sub-user is created. If you have not created a sub-user you will see a screen as follows.
{% endhint %}

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 2 .26.25.jpg" alt=""><figcaption></figcaption></figure>

* In creating a sub-user / reseller please navigate **Users -> Create New User**.

<figure><img src=".gitbook/assets/CleanShot 2024-12-06 at 6 .28.39.jpg" alt=""><figcaption></figcaption></figure>

{% content-ref url="sub-users/create-sub-users.md" %}
[create-sub-users.md](sub-users/create-sub-users.md)
{% endcontent-ref %}

2. Click on the drop-down of providers and select the required **provider**.

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 2 .31.59.jpg" alt=""><figcaption></figcaption></figure>

3. Select the **sub-user.**

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 2 .49.43.jpg" alt=""><figcaption></figcaption></figure>

4. Select the Proxy Format. Using this option, you can obtain the proxies with multiple formats.

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 2 .34.08.jpg" alt=""><figcaption></figcaption></figure>

5. Select the **country**. You can choose multiple countries and generate the proxies.

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 2 .52.30.jpg" alt=""><figcaption></figcaption></figure>

* If you select the country as USA (United States of America) then you get the option of clicking on _**Advance Settings**_**.**&#x20;

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 2 .54.53.jpg" alt=""><figcaption></figcaption></figure>

* If you select **Residential, Premium Residential or X Residential** as the Proxy pool and select the country as the **USA**, it is able to generate either **state-level** or **city-level** proxies by clicking _**Advance settings.**_

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 2 .56.21.jpg" alt=""><figcaption></figcaption></figure>

6. Then enter the **number of Proxies** to be generated.

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 2 .57.56.jpg" alt=""><figcaption></figcaption></figure>

7. Select the Proxy type (i.e. Sticky or Rotating)

* **Sticky**: Same IP for 30 minutes
* **Rotating**: IP Change with every request

<figure><img src=".gitbook/assets/CleanShot 2025-03-28 at 3 .02.22.jpg" alt=""><figcaption></figcaption></figure>

8. Finally you have to click on **Generate** Button. Once the proxies are generated you can either **copy** or **download** the proxies.

<figure><img src=".gitbook/assets/CleanShot 2024-12-06 at 7 .31.50.jpg" alt=""><figcaption></figcaption></figure>
