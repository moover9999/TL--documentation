# Why does TL ISP API V2 have a 28-day billing cycle, while the proxies have a 30-day validity period

Please note that the billing period is 28 days, while the proxy expiration period is 30 days. The 2-day gap is intentionally provided to give customers a window to renew, ensuring uninterrupted proxy usage.

This renewal window allows customers to arrange funds and complete payments smoothly, without any disruptions.
