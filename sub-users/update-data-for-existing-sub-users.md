# Update data for existing sub-users

1. First, navigate to under My Products -> **Residential Proxies -> Users.**&#x20;

{% hint style="info" %}
All the sub-users are displayed in this section along with their user ID, plan name and created date.
{% endhint %}

```
Click on "All time" if the sub-user was created more than 7 days ago.
```

<figure><img src="../.gitbook/assets/Screenshot 2025-08-11 135113.png" alt=""><figcaption></figcaption></figure>

2. Click on the **View** button within each sub-user row to check the details of each sub-user.

<figure><img src="../.gitbook/assets/Screenshot 2025-08-11 133925.png" alt=""><figcaption></figcaption></figure>

3. Then you can see the **sub-user details** as follows. It contains all the transactions and the data usage and balance data.

<figure><img src="../.gitbook/assets/Screenshot 2025-08-11 141300.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
<mark style="color:yellow;">Manage Balance - Quickly add or deduct data for your sub-users in one place.</mark>
{% endhint %}

{% hint style="info" %}
<mark style="color:red;">Balance Updates - View a complete history of all data balance changes for this account. This log helps you track allocations, deductions and adjustments.</mark>
{% endhint %}

**How to remove and add data to sub-users:**

1. **Remove from the sub-user** – Enter `-1` (or the desired amount as a negative number) in the field and click **Update balance**.
2. **Add to the sub-user** – Enter `1` (or the desired amount) in the field and click **Update balance**.

<figure><img src="../.gitbook/assets/Screenshot 2025-08-11 144900.png" alt=""><figcaption></figcaption></figure>

When you want to add or remove data from a sub-user, enter the desired amount and click the “Update Balance” button. A pop-up alert (as shown above) will appear to confirm your action. Review the details, then click “Yes” to proceed.
