# What Is The Common Proxy Error List?

A proxy error list is a collection of common error codes and messages that users may encounter when using proxies. These errors help identify issues like blocked requests, authentication failures, etc.

| **Error Code**                      | **Meaning**                                                                                                          | **Proxy Context**                                                                                                                                                    |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 301/302 Redirects                   | Permanent or temporary redirect                                                                                      | Can lead to access loops or misroutes if not handled properly by the proxy                                                                                           |
| 403 Invalid request configuration   | The proxy request configuration is incorrect or not allowed.                                                         | Often caused by invalid request parameters, unsupported methods or misconfigured proxy settings.                                                                     |
| <p></p><p>404 Not Found<br></p>     | The resource does not exist                                                                                          | The target URL is incorrect or the resource is unavailable.                                                                                                          |
| 407 Proxy Authentication Required   | Proxy server requires authentication                                                                                 | Proxy credentials are missing, expired or invalid.                                                                                                                   |
| 411 Account Blocked                 | Your account has been blocked. If you think it is a mistake, please contact customer support.                        | May occur if the proxy IP has been flagged for suspicious activity, policy violations or abuse by the target service. Contact site support if it’s account-specific. |
| 429 Too Many Requests               | Rate limit exceeded                                                                                                  | Proxy is reusing the same IP too often or sending too many requests in a short time.                                                                                 |
| 464 Connection Not Permitted        | Connection to the specified target is not permitted due to security policies.                                        | Usually occurs when the proxy provider or target site blocks connections to restricted domains or ports because of compliance, security rules, or network policies.  |
| 465 No Proxies Available            | No proxies available in the selected location. Please choose a different targeting configuration or try again later. | Happens when the proxy pool for the chosen country/region is exhausted. Switching location or waiting may resolve the issue.                                         |
| 466 Bandwidth Limit Reached         | You’ve reached your bandwidth limit. Buy more data or upgrade your plan to continue.                                 | Triggered when the allocated data package is fully consumed. Requires purchasing additional bandwidth or upgrading the plan.                                         |
| 467 Session Bandwidth Limit Reached | You have reached your session bandwidth limit.                                                                       | Occurs when the session-based bandwidth allocation is exhausted. Start a new session or upgrade the session plan to continue.                                        |
| 500 Internal Server Error           | Server-side issue                                                                                                    | Proxy server encountered an unexpected issue. May require retrying the request or contacting provider support.                                                       |
| 503 Service Unavailable             | Website Server temporarily down                                                                                      | The target site is unavailable or overloaded.                                                                                                                        |
