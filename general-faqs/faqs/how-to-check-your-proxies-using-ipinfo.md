# How to Check Your Proxies Using IPinfo

#### ✅ What You'll Need:

* Your proxy IP address and port
* The proxy credentials (if authentication is required)

***

#### 🧭 Step-by-Step Instructions:

**🔹 Option 1: Quick IP Check (Without Connecting)**

Use this method if you want to check the metadata of the proxy IP **without connecting through it**.

1. **Go to**: [https://ipinfo.io](https://ipinfo.io)
2. In the search bar at the top, **enter the proxy IP address** (e.g., `123.45.67.89`)
3. Press **Enter** or click the search icon.
4. You’ll see details such as:
   * City & Country
   * ISP / ASN (Autonomous System Number)
   * IP type (Residential, Datacenter, etc.)

> 🔸 This is a good way to check **where the proxy is located** and what kind of IP it is.

***

**🔹 Option 2: Check via Browser Using Proxy Connection**

Use this method to **verify what IP address websites see** when you're connected through the proxy.

1. **Set up the proxy in your browser** or device:
   * Format: `IP:PORT` or `USERNAME:PASSWORD@IP:PORT` depending on the type.
2. Once connected, open your browser and go to:
   * [https://ipinfo.io](https://ipinfo.io)
3. The site will automatically show the IP you're connected with.
4. Confirm that the displayed IP matches the proxy you're using and review the location & ISP info.

> ✅ This helps verify that your proxy is **active and routing traffic correctly**.

***

#### 📌 Tips

* If your proxy requires login, make sure you enter the correct username and password.
* If you're unsure how to set up the proxy on your browser, let us know – we’re happy to help!
* IPinfo will show cached data. If you recently changed your IP or location, try using [https://whatismyipaddress.com](https://whatismyipaddress.com) or similar tools for cross-checking.
